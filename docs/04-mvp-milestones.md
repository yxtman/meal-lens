# MVP 里程碑

## 总原则

先做能演示的闭环，再做真实 App。

## 第 1 周：产品与数据

- 确定功能边界
- 设计数据库
- 准备 30~50 种常见食物数据
- 完成热量计算公式

## 第 2 周：后端核心

- Spring Boot 项目搭建
- 用户信息接口
- 餐食记录接口
- 食物数据库设计

## 第 3 周：分析闭环

- 手动选择食物
- 计算总热量
- 生成分析报告
- 给出简单建议

## 第 4 周：Web Demo

- 上传照片
- 展示分析结果
- 生成演示 GIF
- 写 README 和部署说明

## 第 5 周以后

- 接入真实图像识别
- 开发 Flutter App
- 增加历史趋势
- 优化建议逻辑

## 当前第一版不要做

- 不要一开始就训练模型
- 不要做复杂推荐
- 不要做社交
- 不要追求热量绝对精准

1. 确认项目名
2. 确认第一版先做 Web Demo
3. 确认 MVP 功能范围
4. 开始建 Spring Boot 项目
