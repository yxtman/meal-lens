# 产品方案

## 一句话

给一餐饭做“影响分析”：拍照 → 识别食物 → 估算热量 → 结合个人目标给建议。

## 目标用户

- 想控制体重但不想每天手算热量的人
- 健身增肌/减脂人群
- 想知道自己“这顿吃多了多少”的普通用户

## 核心用户故事

1. 我拍下午餐
2. 系统识别出米饭、鸡腿、青菜
3. 我确认分量
4. 系统告诉我这顿约 700 kcal
5. 结合我的目标是减脂，它提醒我晚餐还剩 500 kcal，并建议多吃蛋白质和蔬菜

## MVP 功能

### 1. 用户基础信息

- 身高、体重、年龄、性别
- 目标：减脂 / 保持 / 增肌
- 活动量：久坐 / 轻度 / 中度 / 高强度

### 2. 餐食照片

- 上传照片
- 后期支持手机摄像头
- 识别结果可手动修正

### 3. 食物分量

- 默认按常见分量估算
- 支持调整：小份 / 中份 / 大份
- 允许手动输入克数

### 4. 热量与营养估算

- 热量区间，例如 650~800 kcal
- 蛋白质、碳水、脂肪
- 钠含量可选

### 5. 影响分析

- 占今日总热量的百分比
- 剩余热量
- 如果目标是减脂，提示是否超标

### 6. 简单建议

- 是否需要散步
- 晚餐建议吃什么
- 蛋白质是否不足

## 明确不做的内容

- 不做疾病诊断
- 不承诺医学级热量精度
- 第一版不做社交
- 第一版不做复杂菜谱推荐

## 成功标准

- 用户能在 1 分钟内得到一餐分析
- 结果能看懂，不只是数字
- 演示时能讲清楚“照片 → 识别 → 计算 → 建议”的闭环
